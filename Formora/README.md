# Formora
# Formora  **Fill Once. Apply Everywhere.**  Formora is a privacy-first, cross-platform application assistant that helps users store their personal information, educational records, employment details, documents, photos, and signatures once, then automatically reuse them across online forms, job portals, government applications, scholarships, admissions, and other digital application systems.  ## Why Formora?  Applying online often requires repeatedly entering the same information and preparing documents with different file size, format, dimension, and naming requirements. Formora eliminates this repetitive work by providing a secure personal vault, intelligent autofill capabilities, and automated document preparation tools.  ## Key Features  ### Profile Vault  Store and manage:  * Personal Information * Contact Details * Addresses * Educational Records * Employment History * Skills & Certifications * Government Identification Details  ### Document Vault  Securely store:  * Passport Photos * Signatures * Resumes * Aadhaar Cards * PAN Cards * Marksheets * Certificates * Supporting Documents  ### Smart Autofill  Automatically detect and fill:  * Text Inputs * Textareas * Dropdowns * Checkboxes * Radio Buttons * Date Fields  ### Smart Upload Engine  Automatically:  * Detect upload requirements * Resize images * Compress files * Convert formats * Generate compliant uploads * Apply required file naming conventions  ### OCR Processing  Extract information from:  * Aadhaar Cards * PAN Cards * Marksheets * Certificates * Resumes  ### AI-Powered Mapping  Supports user-provided AI providers:  * OpenAI * Gemini * Claude * DeepSeek * Ollama (Local AI)  ### Privacy First  * Local-first architecture * AES-256 encryption * SQLCipher database encryption * Secure platform key storage * User-controlled data ownership  ## Supported Platforms  ### Applications  * Android * iOS * Windows * macOS * Linux  ### Browsers  * Chrome * Edge * Firefox  ## Technology Stack  ### Frontend  * Flutter * Dart  ### Browser Extension  * React * TypeScript * Manifest V3  ### Core Processing  * Rust  ### Database  * SQLite * SQLCipher  ### OCR  * PaddleOCR * Tesseract  ### Document Processing  * libvips * ImageMagick * pdf-lib  ##
